# AGENTS

## Зона ответственности

`@module/template-modify` владеет route-level формой шаблона товара.

## Правила

- Шаблон сохраняется как единый агрегат типа товара.
- `productFields` задают структуру товара, `variantFields` — структуру каждого его варианта.
- Порядок строк формы является `sortOrder`.
- Контроллер передаёт input в доменный сервис, транспортный DTO формирует gateway.
- Loader загружает шаблон и определения только назначенных ему свойств из самого
  шаблона. Полный справочник через getCatalogue здесь не загружается.
- Выбор свойства использует InputSelect по образцу поля «Товар» в store-modify:
  поиск через PropertySearchController, server-side search и страницы по 20.
  Догрузка передаёт nextToken; смена/закрытие поиска исключает поздний ответ.
  Выбранные определения сохраняются отдельно от выдачи, в форме остаётся code.
  BOOLEAN по-прежнему сбрасывает и запрещает multiple.
- Как в поле «Товар», текущая выбранная сущность включается в options первой,
  без дублирования в результатах. options/loading/error читаются в теле reactive
  компонента до callback react-hook-form Controller, чтобы изменения store
  действительно обновляли список и индикатор.
